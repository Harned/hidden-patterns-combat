## Текущая задача

Добавить **детализированную 7-state HMM** (вложенные подгруппы КФВ) как
альтернативу 3-state модели из `TASK_SPEC_004`.

## Предметная структура

По `DOMAIN_SPEC.md` расширенная цепочка скрытых состояний:

1. `маневры` (подгруппа маневрирования);
2. `захваты` (подгруппа КФВ);
3. `хваты` (подгруппа КФВ);
4. `обхваты` (подгруппа КФВ);
5. `прихваты` (подгруппа КФВ);
6. `упоры` (подгруппа КФВ);
7. `ВУП` (выведение из устойчивого положения).

Observations остаются ЗАП (TASK_SPEC_003_1).

## Режимы HMM (новый `hmm_mode`)

* ``auto`` (по умолчанию) — сначала попытаться обучить 7-state; при
  неуспехе (guard / sanity / log-likelihood регрессия) откатиться к
  3-state; вернуть ту модель, что прошла проверки.
* ``detailed`` — только 7-state; если guard/sanity не пройдены —
  ``baseline_only`` и честный warning.
* ``basic`` — только 3-state (поведение `TASK_SPEC_004`).
* ``off`` — HMM отключена.

## Guard'ы для 7-state

Дополнительно к базовым (из `TASK_SPEC_004`):

* `MIN_EPISODES_DETAILED` (по умолчанию 120) — 7-state требует больше
  данных;
* `MIN_ZAP_EVENTS_DETAILED` (по умолчанию 60);
* `MIN_ALPHABET_DETAILED` (по умолчанию 3);
* **BIC-гейт**: 7-state допускается только если её BIC ниже 3-state
  (иначе модель слишком сложная для данных, возврат к 3-state).

## Инициализация `A`, `π`, `B`

* `π`: маневры ≈ 0.75, остальные мелкие;
* `A`: почти-диагональная с приоритетной «вперёд-по-цепочке» компонентой
  (`маневры → захваты|хваты|обхваты|прихваты|упоры → ВУП`); подгруппы
  КФВ могут переходить друг в друга как внутри КФВ-слоя, но переходы
  «назад» из ВУП в подгруппу КФВ — с малыми весами;
* `B`: случайная с фиксированным seed + сглаживание.

## Sanity check 7-state

* суммарная масса диагональных элементов `A` + «вперёд-по-цепочке» должна
  быть выше порога (как в TASK_SPEC_004, но с учётом топологии слоёв);
* каждое из 7 состояний должно использоваться в Viterbi-путях (не
  пустое);
* в противном случае возврат к 3-state или `baseline_only`.

## Что должно появиться

1. **algo**:
   * `hpc_algo/hmm.py` — 7-state init helpers, detailed fit с BIC gate.
   * `AnalyzeConfig.hmm_mode` (`auto` / `detailed` / `basic` / `off`).
   * `HMMParameters.variant: Literal["basic_3state", "detailed_7state"]`.
2. **backend**: прокинуть `hmm_mode` через API при необходимости (по
   умолчанию `auto`).
3. **frontend**: бейдж «режим HMM» (`basic` / `detailed`), список
   состояний автоматически подстраивается.
4. **тесты**:
   * 7-state обучается на плотной фикстуре;
   * thin-data: detailed блокируется, fallback возвращает либо
     `basic_3state`, либо `baseline_only`;
   * BIC-гейт блокирует 7-state на фикстуре с малым алфавитом;
   * инварианты (имена состояний, отсутствие `fighter_style`,
     HMM-поля только при `hmm_ready`) сохранены.

## Что НЕ делает этот шаг

* Не меняет формат `ColumnMappingConfig`.
* Не добавляет иерархические HMM / duration models.
* Не меняет схему observation-токенов.

## Definition of Done

1. На плотной synthetic-фикстуре с 120+ эпизодами и 60+ событиями
   `hmm_mode=detailed` возвращает `status=hmm_ready` с 7 состояниями.
2. На meaningly меньшей фикстуре `hmm_mode=auto` возвращает
   `basic_3state` (если он проходит guard'ы) либо `baseline_only`.
3. BIC-гейт работает: 7-state допускается только при снижении BIC.
4. Все прежние тесты и инварианты зелёные.
5. README обновлены, ограничения зафиксированы.
