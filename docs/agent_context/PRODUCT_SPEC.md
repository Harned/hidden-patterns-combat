# PRODUCT_SPEC

## Цель продукта

Создать веб-приложение — инструмент тренера, который по Excel-данным с
эпизодами поединка строит индивидуальный вероятностный профиль поведения
спортсмена и сравнение с агрегатным профилем призёров той же весовой
категории. Это **не** рекомендатель тренировок и **не** генератор
микроциклов.

## Пользователь

Пользователь — специалист, тренер, исследователь или аналитик, который работает с Excel-данными по соревновательной деятельности.

## Основной пользовательский сценарий

1. Пользователь открывает сайт.
2. Регистрируется по email и паролю.
3. Авторизуется.
4. Попадает в личный кабинет.
5. Видит список своих Excel-источников.
6. Загружает новый Excel-источник.
7. Выбирает источник из списка.
8. Запускает или открывает анализ.
9. Видит результаты:
   - графики;
   - таблицы;
   - базовый аудит;
   - диагностические траектории;
   - вероятностные профили;
   - предупреждения;
   - краткие выводы.

## Интерфейсная идея

Общая логика интерфейса похожа на ChatGPT:

- левая панель — список Excel-источников;
- центральная область — результаты работы с выбранным источником;
- пользователь работает не с чатами, а с источниками данных.

## MVP

MVP должен позволять:

1. Зарегистрироваться.
2. Войти.
3. Загрузить Excel.
4. Увидеть список своих Excel-источников.
5. Выбрать источник.
6. Запустить обработку.
7. Увидеть базовые результаты обработки:
   - audit;
   - preview;
   - базовые графики;
   - warnings.

## Необязательно для первого MVP

- сложный UI;
- real-time обработка;
- фоновые очереди;
- платежи;
- роли пользователей;
- командные аккаунты;
- production-grade админка;
- сложная HMM, если еще нет надежного mapping колонок.

## Главное продуктовое ограничение

Продукт не должен показывать пользователю ложную научную диагностику.

Если алгоритм пока может сделать только аудит и базовые распределения, интерфейс должен честно показывать именно это.

## Анти-скоуп продукта

Из встречи 02.05.2026:

- авто-обработка видео в протокол — вне скоупа (стоимость 6–7 тыс. ₽/день);
- генерация тренировочных программ или микроциклов — вне скоупа;
- усреднение по всем участникам категории — запрещено, агрегат строится
  только по призёрам 1–3;
- шкала координационной сложности 1–5 — ноу-хау эксперта, отдельный вопрос;
- расширение на карате или другие виды единоборств — вне скоупа;
- замена существующего пайплайна предобработки 3-уровневой шапки — запрещена,
  переиспользовать;
- обучение нейросетей для классификации действий — запрещено, действия уже
  размечены экспертом.

Финальный вывод по гипотезе «средней формулы победы среди призёров»
делается в отдельной сессии после построения агрегатных моделей и
функции дивергенции (см. `TASK_SPEC_012`).
