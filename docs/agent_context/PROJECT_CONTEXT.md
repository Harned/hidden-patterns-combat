# PROJECT_CONTEXT

## Название проекта

hidden-patterns-combat

## Общая цель

Проект предназначен для анализа соревновательной деятельности спортсменов-единоборцев (самбо) на основе Excel-источников с данными по эпизодам соревновательной деятельности.

На первом этапе проект является исследовательским: нужно построить корректный алгоритм обработки данных и описания индивидуального профиля поединка.

На следующем этапе алгоритм должен быть обернут в независимый модуль обработки информации и использован внутри веб-приложения для оценки результатов спортсменов.

## Конкретный продукт (после встречи 02.05.2026)

Продукт — инструмент тренера, дающий вероятностный диапазон поведения соперника в поединке. Базовая поставка магистерской работы:

1. ~30 индивидуальных моделей (по каждому из финалистов 10 весовых категорий ЧР-2025).
2. 10 агрегатных моделей (только по призёрам 1–3 каждой категории) + функция дивергенции «индивидуал ↔ агрегат».
3. Метрики управления эпизодом и описательная классификация стиля по порогам из YAML.

Продукт **НЕ** является:
- рекомендателем тренировок или генератором микроциклов;
- видео-пайплайном (auto-разметка эпизодов вне скоупа);
- инструментом, расширяемым на карате и другие виды единоборств.

Источник данных — `docs/Оценка СД содержание.xlsx`, лист `Общее`,
~30 спортсменов × 10 весовых категорий, ЧР-2025.

## Предметная идея

Соревновательная деятельность рассматривается как скрытый процесс.

Мы не можем напрямую оценивать эффективность скрытых элементов деятельности, но можем наблюдать итоговые судейские оценки ЗАП.

Идея модели:

скрытая деятельность спортсмена → наблюдаемый результат ЗАП

Базовая причинная цепочка:

маневрирование → КФВ → ВУП → ЗАП

## Будущий продукт

Нужно создать сайт, где пользователь:

1. Регистрируется по email/password.
2. Авторизуется.
3. Загружает Excel-источники.
4. Видит список своих источников.
5. Выбирает источник.
6. Видит результаты обработки:
   - аудит данных;
   - графики;
   - таблицы;
   - диагностические траектории;
   - вероятностные профили;
   - предупреждения;
   - краткие интерпретируемые выводы.

## Идея интерфейса

Интерфейс может быть похож по общей логике на ChatGPT:

- слева вместо списка чатов — список Excel-источников пользователя;
- справа/по центру — рабочая область выбранного источника;
- в рабочей области отображаются результаты обработки алгоритма.

На первом этапе достаточно графиков, таблиц и базового отчета.
