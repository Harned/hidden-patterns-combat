## Маппинг ZAP в реальных файлах

Под `HiddenGroup.ZAP` в `ColumnMappingConfig` нужно собирать **все**
колонки, в которых судья фиксирует факт ЗАП-наблюдения по
`DOMAIN_SPEC.md`. На практике в файлах формата
`docs/Оценка СД содержание.xlsx` это:

- текстовая колонка `ЗАП` со значениями `ЗАП-Р / ЗАП-Н / ЗАП-Т`;
- бинарные/счётные колонки `Удержание`, `На руку`, `На ногу`
  (под супер-заголовком «Завершающие атаку приемы»);
- **числовая колонка `Баллы`** (общая судейская оценка эпизода,
  значения 1/2/4/6/8 и т.п.) — алгоритм трактует её как факт ZAP
  (значение > 0 → канал «Баллы»), не присваивая разным цифрам разные
  ЗАП-классы. Конкретное соответствие 1↔ЗАП-Т / 4↔ЗАП-Р и т.д. — это
  доменное решение и в код не зашито.

Авто-детекция в `algo/hpc_algo/detection.py` подсвечивает «Баллы»
слабым кандидатом ZAP (маркеры `балл`/`оценк`), но обязательное
ручное подтверждение через UI/ColumnMappingConfig сохраняется —
по `AGENT_RULES.md` любой кандидат требует подтверждения до
содержательного анализа.
