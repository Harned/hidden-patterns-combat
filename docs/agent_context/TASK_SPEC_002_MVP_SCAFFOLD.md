# TASK_SPEC_002_MVP_SCAFFOLD

## Текущая задача

На основе согласованной архитектуры реализовать минимальный MVP-каркас.

## Что должно появиться

1. Простая регистрация по email/password.
2. Авторизация.
3. Хранение пользователей.
4. Загрузка Excel-источников.
5. Привязка источников к пользователю.
6. Список источников пользователя.
7. Выбор источника.
8. Запуск baseline-анализа.
9. Сохранение результата анализа.
10. Отображение результата на frontend.

## Processing module

На этом этапе processing module может выполнять baseline:

- чтение Excel;
- data audit;
- preview;
- missing values;
- базовые распределения;
- chart JSON;
- warnings.

Полноценную HMM не реализовывать, если нет надежного column mapping.

## Definition of Done

Готово, если:

1. Пользователь может зарегистрироваться.
2. Пользователь может войти.
3. Пользователь может загрузить Excel.
4. Источник отображается в списке.
5. Пользователь видит только свои источники.
6. Можно запустить анализ.
7. Результат анализа сохраняется.
8. Интерфейс показывает базовые графики/таблицы/warnings.
9. Processing module отделен от backend.
10. Есть команды запуска.
