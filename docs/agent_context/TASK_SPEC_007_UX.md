# TASK_SPEC_007_UX

## Текущая задача

Пользовательский опыт: сделать интерфейс пригодным для ревью
результатов на реальных данных без гаданий и без большого bundle'а.

## Что должно появиться

1. **История запусков** (`AnalysisRun`):
   * `GET /api/sources/{id}/runs` — список run'ов с состоянием, mode,
     временами;
   * в UI — панель/вкладка с прошлыми run'ами; можно выбрать
     прошлый `done`-run и посмотреть его результат.
2. **Preview данных листа**:
   * `GET /api/sources/{id}/sheets/{name}/preview?header_rows=0,1,2&rows=10` —
     первые N строк после flatten, уже известных колонок;
   * в `MappingEditor` — блок «Примеры данных» рядом со списком колонок.
3. **Timeline Viterbi**:
   * визуализация скрытой траектории по эпизодам в `HMMView` —
     sequence-блок с цветовой раскраской по состояниям и линкой
     «показать наблюдения».
4. **Code-split** SPA:
   * `MappingEditor` и `HMMView` как `React.lazy`;
   * целевой размер главного bundle < 450KB gzip.
5. **Vitest** каркас:
   * один smoke-тест, покрывающий рендер `StatusBadge` и
     `ZapChannelsCard` (без сети);
   * `npm run test:unit` в `frontend/`.
6. **Русификация warning'ов**:
   * отдельная карта `WARNING_MESSAGES: Record<code, ru-строка>` на
     фронте; если код неизвестен — показывается бэковое `message`
     как fallback.

## Что НЕ делает этот шаг

* Не меняет алгоритм / доменные инварианты.
* Не добавляет cross-validation — это `TASK_SPEC_008`.
* Не добавляет распределённые очереди/Redis — это `TASK_SPEC_009`.

## Definition of Done

1. На реальном Excel (`docs/Оценка СД содержание.xlsx`) UI позволяет:
   * увидеть историю запусков;
   * открыть прошлый `done`-run и сравнить с текущим;
   * увидеть первые строки любого листа в редакторе mapping;
   * увидеть Viterbi-timeline по эпизодам.
2. Главный bundle SPA уменьшен через code-split (по метрикам `npm run build`).
3. `npm run test:unit` зелёный.
4. Warning'и на UI читаемы по-русски, даже если бэкенд вернул только
   код события.
5. Все предметные инварианты сохранены; тесты `algo + backend + frontend`
   зелёные.
