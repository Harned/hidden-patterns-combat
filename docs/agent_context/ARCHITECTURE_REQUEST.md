# ARCHITECTURE_REQUEST

## Задача

Нужно предложить архитектурное решение для перехода от исследовательского проекта hidden-patterns-combat к веб-приложению.

Важно: архитектуру должен предложить агент на основе контекста, а не просто следовать заранее заданной структуре.

## Что нужно учесть

1. Есть исследовательская задача анализа Excel-источников.
2. Есть будущий сайт для оценки результатов спортсменов.
3. Пользователь должен регистрироваться и авторизоваться.
4. Пользователь должен видеть свои Excel-источники.
5. Пользователь должен загружать Excel.
6. Пользователь должен выбирать источник и видеть результаты обработки.
7. Интерфейс может быть похож на ChatGPT:
   - слева источники;
   - справа рабочая область анализа.
8. Алгоритм должен быть независимым модулем.
9. Backend должен использовать алгоритм.
10. Frontend должен отображать результаты.

## Что нужно получить от агента

Перед написанием кода агент должен выдать:

1. Как он понял задачу.
2. Предлагаемую архитектуру.
3. Предлагаемый стек.
4. Структуру проекта.
5. MVP.
6. Этапы реализации.
7. Риски.
8. Какие части делать сейчас, какие позже.
9. Как проверять результат.

## Ограничения

Пока не нужно сразу писать код.

Сначала нужно архитектурное решение и план.
